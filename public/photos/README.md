# Lab and speaker photos

Square head-and-shoulders photos of principal investigators, one per lab,
named after the lab's data file: `data/labs/jane-doe.yml` → `public/photos/jane-doe.webp`.

The intake workflow writes these automatically from the photo attached to
the submission form: resized to 400 × 400, converted to WebP, all metadata
stripped. If you add one by hand, keep it under 100 KB.

Photos are displayed with the PI's permission, given on the form or in writing.
The repository licences do not grant permission to reuse photos. The PI can
ask a coordinator to remove a photo from the website.

Speaker portraits also go here, with the file name recorded in the event’s
`speaker_photo` field. Obtain permission before publishing a portrait.
The speaker can ask a coordinator to remove it.
