# Lab photos

Square head-and-shoulders photos of principal investigators, one per lab,
named after the lab's data file: `data/labs/jane-doe.yml` → `public/photos/jane-doe.webp`.

The intake workflow writes these automatically from the photo attached to
the submission form: resized to 400 × 400, converted to WebP, all metadata
stripped. If you add one by hand, keep it under 100 KB.

Photos are published under CC BY 4.0 with the PI's consent, given on the form.
